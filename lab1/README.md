# ARTI 403 - Lab 1: Python Basics
## Overview
This repository contains Lab 1 exercises for the ARTI 403 (Image Processing) course, focusing on digital image representation and manipulation using Python.

## Completed Tasks
- **Task 1:** Python programming basics.
- **Task 2:** Loading and visualizing images using `OpenCV` and `PIL`.
- **Task 3:** Saving images to the local disk.
- **Task 4:** Displaying images as `NumPy` arrays to inspect pixel values and dimensions.
